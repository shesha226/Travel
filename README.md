# Travel Experience Platform - Backend API

This repository contains the backend API for the Mini Travel Experience Platform. It is built to handle user authentication and manage travel experience listings.

## Tech Stack
* **Runtime:** Node.js
* **Framework:** Express.js
* **Database:** MongoDB (using Mongoose)
* **Authentication:** JWT (JSON Web Tokens) & bcryptjs for password hashing
* **Deployment:** Render
